Fix these 3 production deployment issues. Do NOT change any backend files.

=================================================================
PROBLEM 1 — API 404 ERRORS (Products not loading)
=================================================================

Console errors:
- /api/products?per_page=4 → 404
- /api/products/featured → 404  
- /api/reviews/featured → 404

These endpoints exist in backend but frontend is calling wrong URLs.

Fix in frontend/lib/api.ts:
- Check every API function that calls these endpoints
- Make sure the base URL comes from process.env.NEXT_PUBLIC_API_URL
- The Axios instance baseURL must be:
  process.env.NEXT_PUBLIC_API_URL || 'http://localhost:8000'
- Do NOT hardcode localhost anywhere

Also check these specific API calls:
- getFeaturedProducts() → should call GET /api/products?is_featured=true&per_page=4
  (if /api/products/featured does not exist in backend, use query params instead)
- getFeaturedReviews() → should call GET /api/reviews?is_featured=true&per_page=3
  (if /api/reviews/featured does not exist, use query params or remove this call)
- getProducts() with per_page param → GET /api/products?per_page=4

Check backend docs at:
https://deluxe-optical-service-backend-production.up.railway.app/docs
and match frontend API calls exactly to what backend endpoints actually exist.

=================================================================
PROBLEM 3 — next.config.js IMAGE DOMAINS
=================================================================

The Next.js Image component needs external domains to be whitelisted.
Add Cloudinary and Railway domains to next.config.js:

In frontend/next.config.js (or next.config.ts), update the images config:

images: {
  remotePatterns: [
    {
      protocol: 'https',
      hostname: 'res.cloudinary.com',
    },
    {
      protocol: 'https', 
      hostname: 'deluxe-optical-service-backend-production.up.railway.app',
    },
    {
      protocol: 'http',
      hostname: 'localhost',
    },
  ],
},

This fixes the 400 errors for product images from Cloudinary.
