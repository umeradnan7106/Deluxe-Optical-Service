IMPLEMENTATION APPROACH
=================================================================

Use Tailwind responsive prefixes:
- sm: = 640px+ (but we treat mobile as <768px)
- md: = 768px+
- lg: = 1024px+
- xl: = 1280px+

For custom 365px breakpoint, add to tailwind.config:
screens: {
  'xs': '365px',
  'sm': '640px',
  'md': '768px', 
  'lg': '1024px',
  'xl': '1280px',
}
