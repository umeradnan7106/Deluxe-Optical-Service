   - Each suggestion row: product thumbnail (small) + product name + price
   - Click suggestion: navigate to that product's detail page
   - Click outside: close suggestions dropdown
   - Show suggestions only after 2+ characters typed
   - Add debounce (300ms) so API isn't called on every keystroke
   - Style: white dropdown, border, rounded-lg, box-shadow, z-index high

3. AUTO LOGOUT FIX
   - Currently user gets logged out after a short time
   - Fix token refresh: when access token expires, automatically use 
     refresh token to get a new access token without logging user out
   - In the Axios instance (frontend/lib/api.ts), add an interceptor:
     * If any API call returns 401 Unauthorized
     * Automatically call POST /api/auth/refresh with the stored refresh token
     * Get new access token
     * Retry the original failed request with new token
     * Only log out if refresh token is also expired/invalid
   - Store refresh token in localStorage (access token in Zustand + localStorage)
   - On app load (layout.tsx): check if tokens exist, if access token expired 
     but refresh token valid, auto-refresh before showing protected content

4. PROMO CODE — PERCENTAGE CALCULATION FIX
   - Currently when percentage promo code is applied, it deducts a fixed amount 
     instead of percentage
   - Fix: if discount_type = "percentage", calculate: subtotal × (value / 100)
   - Example: subtotal Rs. 1,750, code 10% = discount Rs. 175 (not Rs. 10)
   - Fix this calculation in the cart page where coupon discount is computed
   - Also fix it in the order creation (backend) to calculate correctly
   - Backend fix: in POST /api/orders, recalculate coupon discount server-side:
     if promo.discount_type == "percentage": discount = subtotal * (promo.discount_value / 100)
     if promo.discount_type == "fixed": discount = promo.discount_value
